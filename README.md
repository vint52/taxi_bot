# Taxi Bot

Telegram-бот для отслеживания баланса и последних поездок в корпоративном такси.

Важно: это неофициальный бот, разработанный только для работы с такси «Мобиль» в г. Саров.

## Возможности

- Периодически обновляет данные из кабинета такси.
- Показывает текущий баланс и последние поездки по кнопке.
- Автоматически рассылает обновления всем зарегистрированным пользователям, если данные изменились.
- Поддерживает приватный режим с кодовым словом для новых пользователей.
- Даёт администратору доступ к пользователям и логам.

## Как это работает

Бот запускается в контейнере, хранит состояние в Redis и по расписанию опрашивает веб-интерфейс такси. Если баланс или список поездок изменились, бот обновляет данные в Redis и отправляет уведомления зарегистрированным пользователям.

## Требования

- Docker
- Docker Compose
- Telegram Bot Token от [@BotFather](https://t.me/botfather)
- Учётные данные корпоративного такси

## Настройка

1. Клонируйте репозиторий и перейдите в каталог проекта.

```bash
git clone <repository-url>
cd taxi_bot
```

2. Создайте `.env` из шаблона.

```bash
cp env.example .env
```

3. Заполните `.env`.

### Обязательные переменные

- `TG_TOKEN` - токен Telegram-бота
- `TG_ADMIN_ID` - Telegram user ID администратора
- `RDS_HOST` - хост Redis, для Docker Compose обычно `redis`
- `RDS_PASSWORD` - пароль Redis
- `TXI_USERNAME` - логин в кабинете такси
- `TXI_PASSWORD` - пароль в кабинете такси

### Опциональные переменные

- `TG_LOG` - путь к лог-файлу, по умолчанию удобно использовать `/logs/tg.log`
- `RDS_PORT` - порт Redis, по умолчанию `6379`
- `RDS_DB` - номер базы Redis, по умолчанию `0`
- `TXI_UPDATE_PERIOD` - интервал опроса такси в минутах, по умолчанию `25`
- `DEBUG_HTML_DIR` - каталог для сохранения HTML-дампов при ошибках парсинга
- `BOT_SECRET_CODE` - кодовое слово для приватного режима; если не задано, бот работает в публичном режиме

## Запуск

Собрать и поднять контейнеры:

```bash
docker compose up -d --build
```

Для старых версий Compose можно использовать:

```bash
docker-compose up -d --build
```

Посмотреть логи:

```bash
docker compose logs -f tg
```

Остановить сервисы:

```bash
docker compose down
```

## Использование

### Команды пользователя

- `/start` - старт бота и регистрация пользователя
- `/help` - показать приветственное сообщение
- `Проверить баланс` - показать баланс и последние поездки

Если задан `BOT_SECRET_CODE`, новый пользователь сначала должен отправить кодовое слово. До успешной авторизации доступ к данным будет закрыт.

### Возможности администратора

Администратор определяется через `TG_ADMIN_ID` и дополнительно видит кнопки:

- `Логи` - показать последние строки общего лога
- `Пользователи` - открыть список пользователей с inline-управлением

Также доступны команды:

- `/logs <user_id>` - показать активность и последние лог-записи по пользователю
- `/delete <user_id>` - удалить пользователя из базы
- `/addtestuser` - добавить тестового пользователя для проверки Redis

## Хранение данных

В Redis бот хранит:

- текущий баланс
- историю поездок
- список зарегистрированных пользователей
- timestamp последнего обновления

## Логирование и отладка

- Приложение пишет логи в stdout контейнера.
- Если указан `TG_LOG`, логи дополнительно сохраняются в файл.
- При ошибках парсинга HTML бот может сохранить дамп страницы в каталог `DEBUG_HTML_DIR`.
- Каталог `./logs` проброшен в контейнер и используется для логов приложения.

## Разработка

Приложение написано на Python 3.11 и использует:

- `aiogram` для Telegram Bot API
- `redis` для хранения состояния
- `requests` и `lxml` для авторизации и парсинга кабинета такси

Локальная разработка без Docker тоже возможна, но основной сценарий запуска в проекте рассчитан на `docker compose`.

## Безопасность

- Не коммитьте `.env` и реальные секреты в репозиторий.
- Обязательно замените пример пароля Redis на свой.
- Ограничивайте админский доступ через `TG_ADMIN_ID`.
- Если используете `BOT_SECRET_CODE`, задавайте непредсказуемое кодовое слово.
